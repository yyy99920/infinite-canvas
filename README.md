# FRAME · 无限创作画布

支持本机运行和 Vercel 部署的无限画布与创意脚本工作台。推荐 Node.js 24，无需安装第三方依赖。

**部署到 Vercel：请按 [DEPLOY.md](DEPLOY.md) 导入 GitHub 仓库，填写模型环境变量和访问码。** 线上配置由环境变量提供，不依赖服务器进程记忆；网页使用访问码连接，API Key 不发送到浏览器。

以下 `npm start` 和界面填写模型配置的说明适用于本机运行。

```sh
npm start
```

浏览器访问 http://127.0.0.1:4173 。仅监听本机地址。使用 `PORT=其他端口 npm start` 可以改变端口；画布本地数据按浏览器地址和端口隔离。

## 无限画布

支持平移缩放（15%–250%）、适应全部内容、小地图、文字/便签/图片/画框/脚本编辑器、框选与多选、连线、复制删除、撤销重做、JSON 项目导入导出。

双击空白处弹出可搜索的添加菜单，在双击位置创建卡片。双击已有文字编辑。拖动卡片标题移动；完整位于画框内的卡片随画框移动。点击卡片圆点再点击目标卡片建立连线，选中连线后可按 Delete 删除。

| 操作 | 快捷键 |
|---|---|
| 选择 / 平移 / 连线 | V / H / C |
| 添加文字 / 便签 / 画框 | T / N / F |
| 临时平移 | 空格 + 拖动 |
| 缩放 | Cmd 或 Ctrl + 滚轮 |
| 全选 / 复制 | Cmd 或 Ctrl + A / D |
| 撤销 / 重做 | Cmd 或 Ctrl + Z / Shift Z |
| 删除 | Delete 或 Backspace |
| 适应全部内容 | Shift + 1 |

## 创意脚本流程

1. 双击空白处选择「脚本编辑器」，或使用左侧入口。
2. 输入模糊想法，不必提前写完整脚本。
3. 设置时长：5s、8s、10s、自定义正整数秒。设置比例：竖屏 9:16（默认）、横屏 16:9、方形 1:1。
4. 可填写「必须出现」「不要出现」，添加最多 4 张参考图。
5. 配置模型后点击「生成创意方向」。每次真正请求模型生成 4 个不同方向，不用本地模板冒充结果。
6. 比较创意标题、独特角度、钩子、故事、画面风格、适配思路和分镜预览。展开编辑器可并排比较。
7. 选中一个方向后，进入完整分镜脚本继续编辑。替换已有正文前会提示，可撤销；重新生成不会直接覆盖正文。

生成状态可以取消。请求失败时保留已有内容并显示错误；需求、时长、比例或参考图变动后，旧方向会标为过期，需重新生成才能采用。方向和正文一起自动保存、导出到项目文件，正文也可导出 TXT。

## OpenAI 兼容模型配置

点击脚本卡片底部「配置创意模型」：

- **服务地址**：供应商的 Base URL，例如 `https://你的服务地址/v1`。亦可填写完整 `/chat/completions` 地址，系统会规范化。远程服务需 HTTPS，本机服务可用 `http://127.0.0.1:端口/v1`。
- **模型名称**：服务实际提供的模型 ID；不假定截图里的模型存在。
- **API Key**：供应商密钥。无鉴权的本机服务可留空。只保存在服务器进程内存，不写入画布、项目文件或浏览器存储；重启服务后需重新配置。
- **图片输入**：使用参考图时需启用，并确保所选模型支持 OpenAI 兼容 `image_url` 消息。

「保存配置」不会调用模型；「检测当前模型」会发送一次简短文本请求，可能产生少量费用。「读取模型列表」请求 `/models`；若供应商不支持，可手动填写模型名称。重新指定服务地址时不会自动沿用已有 Key。

生成通过本机后端调用 `/chat/completions`，将需求、时长、比例、约束及参考图发送到所配置服务。模型需返回约定 JSON；后端检查 4 个方向、字段和分镜总时长。为提高第三方服务兼容性，使用提示词指定 JSON 格式，不强制依赖 Structured Outputs。超时、无效输出、权限或限流错误均会明确显示，不会自动改用固定示例。单次生成超时 90 秒，不自动重试。

参考：[OpenAI Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。这里采用 Chat Completions 是为了兼容用户选择的第三方服务。

## 数据

画布保存在当前浏览器的 localStorage，只保留一个活动项目。新建与打开可在当前会话撤销，刷新后撤销历史不保留。浏览器存储通常约 5 MB，超出时会提示导出。导出的 `.frame.json` 包含参考图、方向、正文、时长、比例和约束，不包含模型 Key。清理浏览器数据前请导出。

普通图片导入压缩到最长边 1600 像素，脚本参考图压缩到最长边 1024 像素，转换为 JPEG，透明区域变为白色；普通 GIF 按静态图片处理。参考图支持 JPG/PNG/WebP，每张不超过 20 MB。

本版提供创意方向与脚本生成，不渲染视频；未实现账号、云同步或多人协作。

## 源码与验证

- `index.html` / `style.css`：页面与样式
- `app.js`：画布、编辑状态与持久化
- `script-editor.js`：脚本组件与项目迁移
- `creative-ui.js`：模型设置、生成状态、方向选择
- `creative-contract.js`：方向校验与脚本格式化
- `creative-api.mjs`：兼容模型调用与请求校验
- `server.mjs`：本机静态文件与 API 服务，静态资源白名单不会暴露后端源码或配置
- `api/index.mjs` / `hosted-api.mjs`：Vercel 接口、访问码校验和环境变量配置
- `scripts/build.mjs` / `vercel.json`：静态资源白名单构建和 Vercel 路由
- `tests/`：时长、比例、旧项目迁移、API 请求格式、错误处理、Key 脱敏及方向数据往返测试

```sh
npm run check
npm test
npm run build
```

真实服务效果取决于用户配置的模型。无密钥时使用隔离测试响应验证接口与界面，不代表真实模型效果。
